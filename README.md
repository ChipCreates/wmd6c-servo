# wmd6c-servo — DSR-1

Open source digital servo replacement module for the Sony Walkman WM-D6C.
Replaces the CX20084 servo IC, CP304 boost converter, and CN301 power jack
with a single STM32G0B1-based PCB.

## Variants

- **Variant A** — USB-C Power Delivery input (9V PD)
- **Variant B** — Barrel jack input, polarity-agnostic with full protection

## Status

Design phase — schematics in progress. Pending bench verification on target unit.
